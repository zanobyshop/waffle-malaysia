## 🛠️ Cara Integrasi ke BCL.my (zanobyshop.bcl.my)
1. Log masuk ke akaun **BCL** anda di [bcl.my](https://bcl.my).
2. Pergi ke menu **Forms** → Klik **Create Form**.
3. Tetapkan:
   - **Form Title:** `Waffle Pro — Blueprint Kiosk Waffle 2026`
   - **Form Slug:** `kelas-pjj-waffle` (atau `waffle-pro`)
   - **Price:** `RM49.00`
   - **Payment Channels:** Tick FPX Online Banking & DuitNow QR.
4. Pada bahagian **Description / Content Editor**, buka mod **Source / Code (HTML)** dan tampal (*paste*) keseluruhan isi fail `bcl-template.html`.
5. Klik **Save & Publish**.
6. Borang anda akan serta-merta bersiaran di `https://zanobyshop.bcl.my/form/kelas-pjj-waffle`.
